What is CSS Grid?

CSS Grid is a CSS layout system that lets you arrange elements in rows and columns.

Imagine a table with two columns:

Column 1

Column 2

Logo

Navigation

You can create that arrangement with CSS Grid.

Here is a simple example to study:

CSS
header {
    display: grid;
    grid-template-columns: 1fr 2fr;
    align-items: center;
}

Let's explain every line.

Line 1:

CSS
header {

This selects the HTML <header> element. Any CSS rules inside the curly braces will apply to the header.

Line 2:

CSS
display: grid;

This tells the browser to use CSS Grid to arrange the header's direct child elements.

Without this, the browser uses its normal layout rules.

Line 3:

CSS
grid-template-columns: 1fr 2fr;

This creates two columns.

  • 1fr means one fraction of the available space.

  • 2fr means two fractions of the available space.

So the first column receives one-third of the available width and the second receives two-thirds, assuming the available width is divided evenly.

This gives your navigation more space than your logo.

Line 4:

CSS
align-items: center;

This vertically centers the items inside their grid cells.

For example, it helps keep the logo vertically aligned with the navigation menu.

Line 5:

CSS
}

This closes the CSS rule.

Your HTML structure matters

Your header should have the logo and navigation as direct children of the header, or be structured in a way that supports the intended grid.

For example, your existing HTML may look something like this:

Explanation
